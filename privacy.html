Custos – Informativa sulla privacy

Ultimo aggiornamento: 20 ottobre 2026

Custos è un gestore di password per uso familiare, derivato dal software libero Bitwarden. Questa informativa riguarda l'estensione Custos per i browser (Chrome, Edge, Firefox, Safari) e le app Custos.

Quali dati tratta

L'estensione tratta i dati che l'utente vi conserva: credenziali di accesso ai siti, note, carte, identità e altri elementi della sua cassaforte, oltre all'indirizzo email e alle impostazioni del suo account.

Dove vanno i dati

  • La cassaforte è cifrata sul dispositivo con la password principale dell'utente prima di lasciarlo. In forma cifrata viene sincronizzata solo con il server Vaultwarden scelto dall'utente (per la famiglia, un server privato). Chi gestisce il server non può leggerne il contenuto.
  • Le icone dei siti, se l'utente le attiva, sono chieste allo stesso server.
  • L'estensione può comunicare con l'app Custos installata sullo stesso computer, per esempio per sbloccarsi o per aprire un elemento nell'app. Questo scambio resta sul computer.
  • Solo se l'utente lo chiede esplicitamente (controllo delle password esposte), l'estensione interroga il servizio Have I Been Pwned inviando i primi 5 caratteri dell'hash della password, mai la password.

Cosa non fa

  • Non raccoglie statistiche d'uso, non contiene pubblicità né strumenti di tracciamento.
  • Non vende né cede dati a terzi.
  • Legge le pagine web solo per riconoscere i moduli di accesso e compilarli quando l'utente lo chiede o lo ha impostato.

Conservazione e cancellazione

I dati restano sul dispositivo (cifrati) e sul server dell'utente finché l'utente non li elimina o non elimina il suo account. Disinstallando l'estensione si cancellano i dati che conserva sul dispositivo.

Custos – Privacy policy

Last updated: 20 October 2026

Custos is a family password manager derived from the open source Bitwarden. This policy covers the Custos browser extension (Chrome, Edge, Firefox, Safari) and the Custos apps.

What data it handles

The extension handles what the user keeps in it: website logins, notes, cards, identities and other items of their vault, plus the email address and settings of their account.

Where the data goes

  • The vault is encrypted on the device with the user's master password before it leaves it. Encrypted, it is synced only with the Vaultwarden server chosen by the user (for the family, a private server). Whoever runs the server cannot read it.
  • Website icons, if the user turns them on, are requested from the same server.
  • The extension may talk to the Custos app installed on the same computer, for example to unlock or to open an item in the app. This stays on the computer.
  • Only when the user explicitly asks (exposed passwords check), the extension queries the Have I Been Pwned service with the first 5 characters of the password's hash, never the password.

What it doesn't do

  • No usage statistics, no ads, no tracking.
  • No data is sold or shared with third parties.
  • It reads web pages only to recognise sign-in forms and fill them when the user asks or has set it to.

Retention and deletion

Data stays on the device (encrypted) and on the user's server until the user deletes it or their account. Uninstalling the extension deletes what it keeps on the device.
