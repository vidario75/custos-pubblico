Custos

Gestore di password di famiglia, derivato da Bitwarden, che usa un server Vaultwarden privato. Per usarlo serve un account sul nostro server.

Windows

Scarica e installa Versione portatile

Al primo avvio Windows avvisa che il file non è firmato: Ulteriori informazioni → Esegui comunque. Per aggiornare scarica e avvia di nuovo il file: i dati restano.

Android

Scarica l'app

Apri il file scaricato: Android chiede di consentire l'installazione da quell'app → Impostazioni → Consenti. Per aggiornare installa quello nuovo sopra il vecchio: i dati restano.

Firefox

Installa in Firefox

Apri questa pagina con Firefox e conferma l'installazione. Poi si aggiorna da sola.

Chrome

Apri nel Chrome Web Store

Funziona anche con Edge, Brave e gli altri browser basati su Chrome.

iPhone, iPad e Mac

Tramite l'app TestFlight, su invito. L'estensione per Safari è inclusa nell'app.
