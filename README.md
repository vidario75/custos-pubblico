# Custos

Pagine pubbliche di Custos, il gestore di password di famiglia (derivato da Bitwarden):

- informativa sulla privacy dell'estensione: https://vidario75.github.io/custos-pubblico/privacy.html
- aggiornamenti dell'estensione per Firefox: `firefox/updates.json` e i file `.xpi` firmati da Mozilla.
- pagina di download: https://vidario75.github.io/custos-pubblico/ (le app per Windows e Android sono nella release `app`).

Qui non ci sono codice sorgente, chiavi o dati.
